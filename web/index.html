Agent Risk Registry

Prototype

A reference registry that classifies AI agents by risk with defensible, evidence-backed entries — every score is reasoned against quoted evidence and ratified by an accountable human, not self-asserted.

The four scored dimensions shown here are a labelled placeholder for demonstration, pending the real risk-dimension schema. Treat the taxonomy as illustrative, not canonical.

Classify an agent

Pick an example for an instant, identical classification — cached for reliability — or paste your own below to classify it live. Every score is proposed by a model, then overridden by deterministic rules wherever a fact can be pinned down, and ratified by an accountable human before it enters the registry.
