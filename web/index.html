Agent Risk Registry

Prototype

A reference registry that classifies AI agents by risk with defensible, evidence-backed entries — every score is reasoned against quoted evidence and ratified by an accountable human, not self-asserted.

Entries are scored against the ARC 12-dimension classification model (four groups, each dimension tiered 1–3), adopted from RAI's published reference material. This is an independent working prototype, not an official RAI registry.

    Runtime policy gate

    The registry is not just a catalogue — it is something an orchestrator consults at the moment an agent tries to act. The gate maps an agent's evidence-backed risk tier to an org policy action: allow, allow with logging, or escalate to a human. The decision is deterministic — no model runs at enforcement time — and every decision below was computed offline over the committed registry; this page only looks them up.
